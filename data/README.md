## 1. RWIS 도로기상 관측 CSV

`1. 전북도 고속도로 RWIS(도로기상) 관측 데이터.csv`. 관측 지점의 노면 정답과 기상값을 포함합니다. **노면상태·노면온도는 예측 정답이며 미관측 구간 모델 입력에 직접 포함하지 않습니다.** 같은 지점의 RWIS 기상값 역시 미관측 구간에서 이용 가능한 입력인지 별도 검증해야 합니다.

## 품질·정합·모델 활용 원칙

- 원본 `NaN`, `#NUM!`, 빈칸, 숫자 변환 불가값은 구분해 기록합니다. 원본 결측을 0·무강수·non-Ice로 임의 대체하지 않습니다. 기온·이슬점·노면온도의 음수는 유효할 수 있습니다.
- 행 주기, 지점별 중복 시각, 결측률, 단위, 좌표계를 먼저 검사합니다. 서로 다른 출처의 지점번호를 직접 연결하지 않습니다. 표본만으로 시간 보간·10분 재집계를 정당화하지 않습니다.
- 누적·평균 관측량은 해당 시점에 실제 공개된 값만 사용합니다. 미래 관측·검증 지점 통계가 피처에 들어가지 않게 합니다.
- 위험 점수와 변수의 관계는 기온×수분, 바람×습윤, 일사×운량, 교량·지형×기상 같은 동시 조건별로 검토할 수 있으나 이는 분석 가설입니다. 현재 한 시점·10개 지점 표본으로 시간적 동시성·인과관계·성능을 주장할 수 없습니다.
- RWIS 노면온도·노면상태·그 파생값은 정답입니다. 예측 노면온도를 분류 입력으로 쓰려면 out-of-fold 예측이 필요합니다. 검증 관측소 통계는 훈련 피처를 만드는 데 쓰지 않습니다.
- 이 문서는 데이터 정의를 갱신하며 학습 코드·라벨 정책을 자동 변경하지 않습니다. PDF로 확인된 코드와 공식 평가 규정을 바탕으로 별도 정규화 매핑을 작성해야 합니다.
