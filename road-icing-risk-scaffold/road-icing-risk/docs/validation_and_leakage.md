# 홀드아웃·누수 방지 정책

1. **관측소 ID 기준 분리:** 같은 RWIS 관측소의 다른 날짜가 train/validation에 동시에 나타나면 안 됨. 대회 지정 미관측 관측소는 훈련과 튜닝에 사용 금지.
2. **타깃 피처 금지:** `road_surface_temp_c`, `road_state`, `is_ice` 및 해당 시각의 정답에서 직접 유도한 정보는 모델 입력 금지.
3. **검증 소스 조건:** 대회에서 사용하는 ASOS·AWS 및 실제로 미관측 구간에 제공되는 정적 지리공간 정보만 입력 피처 후보로 허용. 미관측 구간에서 관측할 수 없는 RWIS 값은 금지.
4. **시간 검증:** 동일 시각 기상자료 이용이 허용되는 공간 보간인지, 몇 시간 앞선 미래 예보인지 문제에서 먼저 확정. 미래 관측정보가 들어가면 누수.
5. **공간 검증:** 관측소 고유 ID 자체를 특성으로 사용하지 않음. 최근접 RWIS 좌표와 해당 관측소 자기 자신의 정답을 섞지 않음.
6. **정상화:** scaler/imputer/encoder는 훈련 폴드만 fit. 모델 선택에 holdout 측정치 사용 금지.
7. **물리 타당성:** 결빙은 단순히 기온이 0보다 낮은 것과 다름. 실제 도로 노면 `Ice` 상태만 레이블.
8. **위험도:** 결빙확률(모델 출력)과 도로시설의 노출·취약도(의사결정 지표)는 구별.
